# jaysystems.dev — personal site

Vanilla HTML, CSS, and JavaScript portfolio for [Jay](https://github.com/jayjz). Offline-first tools shaped by ten years of HVAC and construction field ops.

[![Live](https://img.shields.io/badge/live-jaysystems.dev-success?style=flat-square)](https://jaysystems.dev)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=flat-square)](https://opensource.org/licenses/MIT)

No frameworks. No build step. Static files deployed on Vercel.

- HTML5, CSS3 (custom properties, Grid, Flexbox)
- Vanilla JS (ES6+)
- Space Grotesk + JetBrains Mono

## Local preview

```bash
git clone https://github.com/jayjz/movingbytes-dev-v2.git
cd movingbytes-dev-v2
python -m http.server 8000
```

Open the printed local address. There is no compile step.
