## Overview

Cinematic, high-performance portfolio for local-first agent systems and ops tooling under real constraints (consumer GPUs, field connectivity, human review). Built entirely with vanilla HTML, CSS, and JavaScript.

## Features

- **Cinematic Design** — Dark theme, atmospheric effects, disciplined motion
- **Zero-Dependency** — No frameworks or build tools
- **Fully Responsive** — Mobile to 4K
- **Accessible** — Semantic HTML, ARIA, keyboard navigation
- **Performance-First** — Instant loads, progressive enhancement

## Tech Stack

- HTML5, CSS3 (custom properties, Grid, Flexbox), Vanilla JS (ES6+)
- Deployed as static site (Vercel / Cloudflare / Netlify)

## Local Development
