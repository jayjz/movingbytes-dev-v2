Problem

Local agents on 8–16 GB cards fail predictably: runaway generation, context blow-ups, thermal stress, and strategy thrash that OOM the only GPU available.

Constraints

8 GB VRAM budgets, thermal limits, offline field use, and irreversible actions that require human sign-off.

Architecture Decisions

FastAPI control plane with Economic Gatekeeper, thermal/VRAM circuit breakers (503), context ceilings (413), tool discovery, and durable audit logs. Agents negotiate strategy; the plane can refuse unsafe work.

Current Verified State

Wedge A verified under Mock engine (CI + no-GPU path). Real Fast-Swap / KV survival on 8 GB remains gated research (Wedge B). No production claim for unproven swap behavior.

02 Unhinged Agent Phase 1 PoC
Updated: Aug 24, 2026•Edge + Host

Problem

Cloud voice assistants violate privacy and fail without internet. Local inference requires strict memory and state management.

Architecture Decisions

Thin-client ESP32 edge streams raw audio via WebSocket to local RTX 4060 host running Whisper.cpp + local LLM. FSM handles listening vs processing states to prevent audio bleed.

PRINCIPLES

How systems survive reality.

01

Local-First, Constraint-First

Design for the hardware and connectivity you actually have. 8 GB VRAM and spotty field signal are not edge cases — they are the baseline.

02

Human-Accountable by Default

Irreversible actions (write-offs, parts orders, schedule changes) require explicit human review. Agents propose; operators decide.

03

Honesty Over Hype

State what is verified and what is research. A Mock-verified control plane with clear non-claims is more useful than an inflated production story.
