## Scope and visual review

The personal opening retains its wording, background, interests and small
Observer. Space Grotesk and a system Georgia serif distinguish making from
questioning. Perspective, principles, explorations and the field note have
different reading rhythms; the engineering archive follows in its original order.
No case-study research, generated content, evidence pins, data, favicon, public
routes or deployment configuration changed.

Jonah now has an uncropped image encounter, a separate warm reading invitation,
and visible museum credit. The later artistic interpretation is distinguished
from Scripture and historical reconstruction. The existing reader link remains.
The TEMPER instrument uses synthetic unit-test inputs at a pinned revision,
with explicit definitions and limitations; it makes no model-performance claim.

Actual Chromium screenshots were inspected at **320, 390, 768, 1280 and 1440px**.
Review covered the opening, Jonah and model sections at every width, plus
principles and the field note on desktop. Narrow screens stack the story and
use two decision columns; tablet/desktop show four decisions. No text clipping
or horizontal overflow was observed. The image stays complete. Copy measure,
spacing, headings, CTA placement and dark/light contrast were reviewed visually.
Fallback-font captures were reviewed as well as captures with the external font
stylesheet available. Existing optional font loading may retain a system face
on a first visit; screenshots do not guarantee a particular font will load.

The unfocused fixed skip link appeared in tall element captures even though its
viewport bounds were offscreen. Clipping its unfocused state removes the stray
painting; focus removes the clip. Tab/Enter still reaches and focuses main.

## Evidence, performance and limitations

- [Design choice and references](../../editorial-observatory.md),
  [image rights and checksum](../../../assets/jonah/ATTRIBUTION.md), and
  [instrument inputs and arithmetic](../../threshold-instrument.md).
- The existing deployed [Jonah reader](https://biblemap-pink.vercel.app/jonah/)
  was retrieved through Firecrawl with HTTP 200. Its text distinguishes World
  English Bible Scripture, geography, and optional Pascal/Aquinas perspectives.
  This was a content retrieval, not end-to-end testing of BibleMap.
- Added runtime assets: one 85,395-byte lazy-loaded JPEG with explicit dimensions
  and one 1,855-byte unminified script. No dependency, new font request, runtime
  data fetch, tracker, canvas, model call or perpetual animation was added.
  Local browser timings are diagnostic only, not field Core Web Vitals or a
  production performance claim. In the completed local run, home CLS was 0 at
  every width and recorded resource transfer was 152,606 bytes; LCP ranged from
  228 to 856ms. These are local Chromium observations, not network-throttled or
  cold-device benchmarks.
- Local Node is 25.0.0; repository CI specifies Node 22. Chromium was exercised;
  Safari, Firefox, physical devices and a screen reader were not tested.
- Full diff reviewed for unsupported claims, unrelated changes and private
  material. Public copy preserves the existing proposed personal voice; Jay's
  review is still required before publication, especially the existing field note.
  Automated accessibility checks and screenshots do not replace that review.
- Vercel's bot provided this actual branch
  [preview](https://movingbytes-dev-v2-git-feat-edi-e17ecc-elliotandersons-projects.vercel.app).
  Direct deployment listing through the Vercel connector lacked team permission;
  no team permission or production setting was changed. Local browser QA is not
  a claim of hosted preview verification.
