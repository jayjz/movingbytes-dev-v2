Decisions and authority

When is a decision authorized to become an action?

  1. Observation available
  2. Signal created
  3. Execution eligible
  4. Risk admitted

SHAD0W separates chronological availability, simulation lifecycle and an independent paper-risk gate. Eligibility alone does not grant execution authority.

  • SHAD0W

    implemented

    Separates simulation state from execution authority.

    Source and tests inspected; no live-capital or profitability claim.

Pinned source and regression tests were inspected, not rerun for the site. This is a technical research simulator; profitability and live-capital trading are unverified.

03 / coordinate

Coordination and infrastructure

How can agent workloads meet constrained compute?

  1. Request
  2. Lease / thermal / capacity gates
  3. Admit or reject

AetherForge checks bounded admission and switching economics before a strategy is applied. A capacity rejection supplies a retry interval; permission to retry is not a successful admission.

  • AetherForge

    experimental

    Makes compute admission an explicit decision.

    Recorded mock probes only; physical GPU swapping remains unverified.

  • Unhinged Agent

    experimental

    Explores bounded state and interruption at the device boundary.

    Feature revision; physical hardware loop unverified.

Four controlled mock probes and five route tests were recorded. Physical GPU fast-swap behavior, hardware recovery and performance benefits remain unverified.
