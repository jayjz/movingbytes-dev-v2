The Problem

Field technicians waste nearly 30% of their first-visit time dealing with missing parts, incomplete diagnostic histories, or fighting disconnected enterprise software in dead zones.

Most "AI for Operations" tools assume perfect 5G connectivity and give agents autonomous permission to rewrite inventory or schedules. In the physical trades, an agent making an unverified $2,000 supply house order or botching a dispatch queue is catastrophic.

Architecture Decisions

1. Offline-First PWA Sync — The pre-departure checklist and diagnostic history live in a Progressive Web App that treats local storage as the master state. If the tech enters a basement mechanical room with zero signal, the app remains fully interactive. Payloads are queued and synced asynchronously upon reconnection.

2. Human-In-The-Loop (HITL) Gate — Agents analyze diagnostic data and propose parts orders or schedule adjustments, but they are architecturally blocked from execution. A human operator must explicitly authorize any state change that impacts physical inventory or capital.

Business Impact & JTBD

Maximizing First-Visit Resolution. The core Job-to-be-Done is eliminating the "second truck roll." By ensuring the technician arrives strictly verified for the specific equipment they are servicing, operational overhead plummets.

My 10+ years leading HVAC and construction crews informed every line of this architecture. It operates under the assumption that field conditions are hostile, signal is unreliable, and safety requires an operator's consent.

class OperatorApprovalGate:
    def __init__(self):
        self.pending_actions = {}

    def propose_action(self, agent_id: str, action: dict) -> str:
        """Agents can only propose, never execute."""
        action_id = generate_id()
        self.pending_actions[action_id] = {
            "agent": agent_id,
            "cost_impact": action.get("estimated_cost", 0),
            "payload": action,
            "status": "pending_human_review"
        }
        return action_id

    def execute_action(self, action_id: str, operator_id: str):
        """Only an authorized human can flush the queue to physical ops."""
        if action_id not in self.pending_actions:
            raise ValueError("Invalid or expired action ID.")
            
        action = self.pending_actions[action_id]
        logger.info(f"Operator {operator_id} authorized action {action_id}.")
        # Flush to ERP / Inventory API
        return dispatch_to_erp(action["payload"])

Trade-offs & Decisions

Accepted

Eventual Consistency

Offline-first means accepting eventual consistency. Techs might briefly see stale dispatch data, but it prevents the UI from locking up in cellular dead zones.

Rejected

Autonomous Parts Ordering

Blocked entirely. An LLM hallucinating a $1,500 compressor order is an unacceptable risk. The system requires an explicit operator payload flush.
