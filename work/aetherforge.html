The Economic Gatekeeper

Control Plane

A pre-execution filter that evaluates agent strategy proposals against a resource cost model. It rejects "doomed" strategies before inference begins.

Why it matters: Prevents runaway compute costs and protects the GPU.
Applied in: AetherForge

VRAM Circuit Breaker

Resource Guardrail

A hard kill-switch triggered when GPU VRAM usage exceeds a safety threshold. Immediately aborts generation to prevent system OOM.

Why it matters: Ensures the host OS remains responsive and prevents data corruption.
Applied in: AetherForge

AetherForge

Hardware-aware safety and control plane for local AI agents on consumer GPUs. Designed for the messy reality of 8 GB VRAM budgets, thermal throttling, and irreversible actions.

Wedge A (Mock-verified) · Active Development

The Problem

Local AI agents on consumer hardware fail in ways cloud demos never predict. A single runaway generation loop can exhaust an 8 GB VRAM pool in seconds. Context windows balloon without warning. Thermal throttling cascades into strategy thrash, where agents retry failed operations and OOM the only GPU available.

The industry answer is "just use a bigger GPU." That's not an architecture. That's a budget request. I needed a control plane that treats hardware limits as first-class constraints, not edge cases to be handled after the fact.

Architecture Decisions

AetherForge sits between the agent and the inference engine. It is a FastAPI control plane that negotiates strategy, enforces resource budgets, and can refuse unsafe work before a single token is generated.

Three core subsystems enforce safety:

1. The Economic Gatekeeper — Evaluates agent strategy proposals against a cost model before execution. If a strategy requires more VRAM than the budget allows, the plane rejects it and requests a fallback strategy. No tokens are wasted on doomed attempts.

2. Thermal / VRAM Circuit Breakers — Real-time hardware telemetry feeds into hard limits. If VRAM usage exceeds 85%, the plane returns HTTP 503. If context size exceeds the ceiling, it returns HTTP 413. These are not suggestions. They are kill switches.

3. Durable Audit Logs — Every strategy negotiation, every rejection, every circuit breaker trip is logged. Agents operate under the assumption that a human will review the trace.

Business Impact & JTBD

De-risking the deployment. The Economic Gatekeeper isn't just a token-saver; it operates on Expected Value. By rejecting unsafe or overly complex agent strategies before execution, the system prevents cascading failures that lead to operational downtime.

In a field-ops environment, an agent hallucinating a parts order or freezing a dispatch queue has a massive real-world cost. AetherForge treats reliability and cost-predictability as the primary Jobs-to-be-Done for any enterprise AI integration.

vram_circuit_breaker.py 
from fastapi import HTTPException
from dataclasses import dataclass

@dataclass
class HardwareBudget:
    vram_limit_gb: float = 8.0
    thermal_threshold_c: float = 83.0
    context_ceiling: int = 32768

class VramGuardrail:
    def __init__(self, budget: HardwareBudget):
        self.budget = budget

    def check(self, current_vram_gb: float) -> None:
        usage_ratio = current_vram_gb / self.budget.vram_limit_gb
        if usage_ratio > 0.85:
            raise HTTPException(
                status_code=503,
                detail=f"VRAM guardrail triggered: {usage_ratio:.1%} "
                       f"of {self.budget.vram_limit_gb}GB budget. "
                       f"Aborting generation."
            )
        if usage_ratio > 0.70:
            logger.warning(
                f"VRAM pressure: {usage_ratio:.1%}. "
                f"Throttling strategy complexity."
            )

Trade-offs & Decisions

Accepted

Mock Engine for CI

Wedge A is verified under a Mock engine (no GPU required). This enables CI testing but means real GPU behavior remains unproven.

Deferred

Fast-Swap / KV Survival

True context survival during VRAM pressure (Wedge B) requires live hardware testing. Not yet verified. No production claim made.

Rejected

Cloud Fallback

Falling back to a cloud API when local VRAM is exhausted violates the local-first principle. The plane prefers to refuse work rather than leak data.

Current Verified State

Wedge A is verified under the Mock engine with full CI coverage and no-GPU path testing. The Economic Gatekeeper, circuit breakers, and audit logging are functional and tested.

Wedge B remains gated research. Real Fast-Swap and KV survival on consumer hardware has not been validated. I will not claim production readiness for unproven swap behavior.
